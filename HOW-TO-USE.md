# How to use this starter project

1. Read `README.md` for scope and rules.
2. Review `Test-Scenarios.xlsx` to understand coverage.
3. Execute each row in `Test-Cases.xlsx` on the live application.
4. Replace `Not executed` in Actual Result with what you actually observed, and change Status to Pass, Fail or Blocked.
5. For every confirmed, reproducible failure, add a row to `Bug-Reports.xlsx`, link its test case, and save evidence in `Screenshots/`.
6. Update `Test-Execution-Report.md` with actual totals and limitations.
7. Keep exploratory name/mobile checks as observations until expected validation rules are confirmed.

The live site's behavior may change. Always record the date, browser and exact test data used.
